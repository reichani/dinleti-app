# Okurio v2.6.0 Priority Package

## P0 — Release blockers

1. Implement the contextual word-help card directly in `src/App.jsx`.
2. Open an age-appropriate short definition when an editorially approved target word is tapped or activated by keyboard.
3. Keep reading position unchanged while the definition card opens and closes.
4. Keep pronunciation optional and separate from normal story reading.
5. Replace the legacy `Yardım · Oku` control with contextual word-help guidance.
6. Update Playwright tests to validate the real word-card flow.
7. Prevent repeated insertion of the same user document into the catalog.
8. Keep pasted user text inside the full reader.

## P1 — Reader-first mobile layout

1. Replace the waveform with a thin progress bar.
2. Use a one-line expandable reading-mode selector.
3. Reduce mode-description visual weight.
4. Combine speed, voice and sleep controls into one compact toolbar.
5. Standardize primary copy as `Okumaya başla` and `Okumaya devam et`.
