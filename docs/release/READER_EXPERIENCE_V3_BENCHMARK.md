# Reader Experience v3 — Benchmark Criteria

This benchmark compares interaction quality, not brand appearance.

## Kindle-level expectations

- Reading position remains stable and predictable.
- Typography changes do not lose the user's place.
- Controls recede when reading and never cover text.
- Manual navigation always has priority over automation.
- Reopening or resuming returns to the exact position.

## Google Play Books-level expectations

- Responsive behavior is consistent across Android devices.
- Theme, type size and line spacing update without layout failure.
- Progress and seek behavior are understandable and reversible.
- Screen rotation and browser viewport changes preserve context.

## Okurio differentiation

- Optional active-word support.
- Optional continuous active-sentence focus.
- Dyslexia and ADHD-oriented spacing and focus tools.
- Three explicit reading modes sharing one position model.
- Calm motion and reduced-motion equivalents.

## Scoring

Each area is scored 0–3:

- **0 — Broken:** task cannot be completed or position is lost.
- **1 — Functional:** task completes with visible friction.
- **2 — Polished:** predictable and comfortable with minor issues.
- **3 — Reference quality:** calm, immediate and consistent.

Mandatory areas:

1. Position continuity
2. Highlight accuracy
3. Sentence focus quality
4. Scroll behavior
5. Manual override
6. Pause/resume
7. Seek
8. Typography resilience
9. Settings interaction
10. Mobile responsiveness
11. Accessibility
12. Performance

Release threshold:
- no score below 2;
- position continuity, highlight accuracy and scroll behavior must score 3;
- average score must be at least 2.5;
- Samsung S24+ and one iPhone must independently meet the threshold.
